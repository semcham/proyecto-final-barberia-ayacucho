# Componentes arquitectónicos

Los componentes son los **seis módulos** del backend (C4 nivel 3): cinco de negocio y un núcleo compartido. Cada uno nace de requisitos concretos y publica una interfaz pública. Los módulos con dos responsabilidades cercanas se dividen internamente en **submódulos**, cada uno con sus cuatro capas. Etiqueta de estado de todos: **planificado**.

## 2. Responsabilidades y límites

| Módulo                      | Hace                                                                                                                             | **No** hace                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| M01 Acceso y barberías      | Autentica, emite token con rol y tenant, registra consentimiento; crea el tenant, guarda datos comerciales y estado              | Decidir si una barbería puede operar (eso lo decide M03); reservar; cobrar                               |
| M02 Catálogo y citas        | Mantiene catálogo y disponibilidad configurada; calcula disponibilidad y reserva con garantía en PostgreSQL                      | Cobrar; enviar correos (publica eventos)                                                                 |
| M03 Suscripciones y pagos   | Mantiene la máquina de estados de la suscripción y las reglas por plan; aísla al proveedor de pagos y valida y registra webhooks | Gestionar citas o usuarios                                                                               |
| M04 Asistente IA y reportes | Interpreta intención y ejecuta herramientas cerradas; calcula reportes de solo lectura                                           | Leer la base de datos libremente; confirmar reservas sin casos de uso; modificar datos                   |
| M05 Notificaciones          | Envía correos y mensajes de WhatsApp desde eventos y recordatorios                                                               | Bloquear una operación si el envío falla; leer datos de otros módulos (recibe lo necesario en el evento) |
| M06 Núcleo compartido       | Provee servicios técnicos comunes                                                                                                | Contener reglas de negocio                                                                               |

## 3. Eventos de integración

| Evento                                                                                                                            | Publica       | Escucha                    | Efecto                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------- | -------------------------- | --------------------------------------------------------------------------- |
| `PagoConfirmado`                                                                                                                  | M03 (`pagos`) | M03 (`suscripciones`)      | La suscripción pasa a ACTIVE (idempotente). Es un evento interno del módulo |
| `PagoRechazado`                                                                                                                   | M03 (`pagos`) | M03 (`suscripciones`), M05 | La suscripción sigue o pasa a PAST_DUE; aviso                               |
| `CitaCreada` / `CitaCancelada` / `CitaReprogramada` (con barbería, servicio, fecha, hora y datos de contacto mínimos del cliente) | M02           | M05                        | Notificación al cliente por su canal (correo o WhatsApp)                    |
| `SuscripcionPorVencer` / `SuscripcionVencida` / `SuscripcionSuspendida`                                                           | M03           | M05                        | Aviso al propietario                                                        |
| `BarberiaSuspendida`                                                                                                              | M01           | M05, M06                   | Aviso y auditoría                                                           |
